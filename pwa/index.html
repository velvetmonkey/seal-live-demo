    What this proves — and what it does not
    
      
    
        
    
          
    ✓ Proves
    
          
    The mediation decision: a state transition that violates the capability policy
            cannot be executed once it reaches seal (the sha256-pinned kernel whose decision logic is conformance-tested against the Lean-4 proof),
            modulo assumptions A1–A3. Same input → byte-identical verdict; re-derivable here, in your browser.
    
        
    
        
    
          
    ✗ Does NOT prove
    
          
    It does not prove the agent is safe — a fooled agent can still leak what it reads.
            It tests, but does not prove, the host/container wiring. The config has a real Ed25519 signature,
            but this browser has no independently provisioned operator-key pin, so authority remains visibly
            unpinned. No third party (incl. ARIA) certifies anything here.
    
          
    In the Policy Lab, the quorum does not bind the £40,000 or
            supplier-77: the deployed consensus kernel ratifies the
            tool name, so the same 2-of-3 certificate would admit any other
            payments.send call. Argument-level binding is proven
            (byteConsensusKernel) and not yet wired.
